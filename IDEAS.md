# Ideas — claude-bundle

Forward-looking improvement proposals (enhancements, not bug reports). Bugs and
defects live in `FINDINGS.md`. Status: `proposed` → `accepted` / `done` / `wontfix`.

Only `proposed` entries live here. A resolved idea — shipped, declined, or found
already implemented — is **moved** to `IDEAS-archive.md` with a verdict and the
reason, append-first then delete, so a crash mid-move leaves a visible duplicate
rather than a silent loss. The archive is the audit trail; entries are never
deleted from it.

Before proposing: check `IDEAS-archive.md`. The 2026-07-13 batch was largely
resolved by reading the code rather than the proposal — several ideas described
problems the code had already solved, and one asked for something the hook it
targeted cannot do. Verify the diagnosis against the source first.
