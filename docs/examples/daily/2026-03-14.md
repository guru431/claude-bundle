# Daily 2026-03-14

## demo
Chased a nightly export that silently produced an empty file roughly one run in
five. The writer opened the destination on a network share before checking that
the share was mounted, so on a slow mount it created a zero-byte file and the
integrity check downstream compared it against itself. Moved the mount check
above the open, and made the exporter write to a `.part` file renamed only after
the row count matches. Verified across twenty consecutive runs.
